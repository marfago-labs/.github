# marfago labs

**Personal R&D** for research intelligence: arXiv & YouTube ingest, LLM compression, embeddings, NER benchmarks, and agent tooling.

Maintained by **[Marco Fago (@marfago)](https://github.com/marfago)** — ML/AI engineer, Dublin.

---

## What this org is

`marfago-labs` groups **experiments and products** that belong together technically (ingest → compress/summarize → embed → discover → evaluate NER), separate from unrelated personal repos on [@marfago](https://github.com/marfago).

Public portfolio work (e.g. [ArXplorer](https://github.com/marfago/ArXplorer), [arxiv-sync-mcp-server](https://github.com/marfago/arxiv-sync-mcp-server)) stays on my **personal** profile.
